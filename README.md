# A-shygun Dripfetch

## How do I install these formulae?

`brew install a-shygun/dripfetch/<formula>`

Or `brew tap a-shygun/dripfetch` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "a-shygun/dripfetch"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
